# Component 04 implementation

The bounded Boolean subsystem now contains a dependency-free C++17 source-facet
triangulation stage. It consumes only immutable `validated_operand` data and the
committed Component 03 precision context, materializes the predecessor projection
basis, runs a bounded full-rescan semantic ear reference, reconstructs source
boundary and internal-diagonal roles from final triangle cycles, encodes owner-free
semantic and exact-layout digests, and invokes an independent topology/codec
verifier before publication.

The V1 indexed provider deliberately retains complete active-point and active-segment
dependency sets and is differentially checked against the executable full-rescan
reference. This prioritizes complete invalidation and deterministic bounded
termination; the configured ring/work guards prevent unbounded adversarial work.
Internal diagonals are schema-fixed as ineligible source features, source-edge
broad-phase candidates, symbolic owners, and winding barriers.

Normative tests cover convex and concave closed shells, coherent-basis linkage,
projection/orientation evidence, complete candidate traces, source-edge sharing,
presentation canonicalization, legal alternative triangulations, independent
mutation rejection, scale/translation properties, resource limits, and cancellation.
